# GitPier installer background

Generated with `CLANG_MODULE_CACHE_PATH="$PWD/.cache/clang" swift Scripts/generate-installer-background.swift`.

Canvas: 720 × 420 pt. PNG: 1440 × 840 pixels (2x); TIFF: 1x + 2x representations for Finder. The background draws only brand text, a directional arrow and bilingual installation guidance. Finder displays the actual GitPier.app icon and /Applications symbolic link; icons are never painted into the background.

All drawing uses AppKit system fonts and original geometric primitives. No external images, online resources, personal data or additional licenses are required. The canonical application icon remains unchanged in Resources/Branding. Layout and display must be inspected in Finder; viewing this background alone is not installer acceptance.

# Native Experience Refinement — implementation and acceptance

Baseline: GitPier 2.1.0 (35), `main` at `10d3165`, macOS 27.0.1 (26A434), Xcode 27.0 / macOS SDK 27.0. The comparison build is the locally retained v2.1.0 release candidate whose bundle was verified against the published DMG. The product version and the minimum macOS 14 target remain unchanged while this work is in development.

## Design decisions

- Follow Apple's [Designing for macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos/) and [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) guidance. Keep the system unified window toolbar and native Sheets, Popovers, menus and Alerts. The sidebar is the primary material surface; reading and editing panes use opaque system colors. Use the newer window and corner APIs only when both compiler and runtime support them. See [Modernize your AppKit app](https://developer.apple.com/videos/play/wwdc2026/289/).
- Buttons, focus, selected rows, section titles, panel edges and outcome feedback share semantic colors and metrics. Accent does not replace text or symbols. Keep a static indicator for indeterminate progress with Reduce Motion.
- Keep the existing `UnifiedScrollbars`, `OverlayScrollbars` and `OverlayScrollThumb` behavior. Native presentation roots must install `AppAppearance`; Popovers retain their native background and `AppPopoverAppearance`.

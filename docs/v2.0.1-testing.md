### Incremental target-lifetime correction

The original read-only reviewer identified a concrete shared-state flaw: after no-op Merge & Push returned unknown (HEAD still equals the original reviewed Hash), an unrelated staging operation resets the shared output result, or a refresh is already in flight when Retry starts. The old refresh guard can clear `conflictPush`; a second unknown retry failed to restore it, allowing a later Retry to fall back to the ordinary default destination. Output presentation is no longer the target's lifetime predicate. Existing explicit abort/success/rejection behavior is retained.
